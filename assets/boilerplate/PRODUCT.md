# Product

## Platform

web

## Purpose

Reusable Django development starter for fullstack and REST APIs. The included project workflow is an example to extend, not a claim to implement an arbitrary customer's domain.

## Audience and tasks

Developers copy the starter and add domain applications. End users authenticate, find/create/edit their projects and change lifecycle status. Staff operate scoped records in Unfold; superusers manage identities.

## Constraints

Admin always Unfold; public templates use skill-defined semantic tokens. Modes fullstack/api/hybrid have explicit routes. Single-owner access, server validation, CSRF/session auth, DB constraints and isolated tests are baseline. No seeded demo account, fake metric, or automatic production deployment.
