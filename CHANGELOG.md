# Changelog

## 0.1.0 — 2026-10-13

Rilis pertama skill Django Development dan boilerplate aplikasi.

- Panduan startup, arsitektur, struktur folder/code, ORM, migrations dan shared workflows.
- Panduan fullstack Django, REST Framework, drf-spectacular dan WhiteNoise.
- Admin selalu Django Unfold; peta fitur, components, recipes dan integrasi opsional.
- Panduan design system, permission/security, testing, deployment dan upgrade package.
- Generator proyek dengan mode fullstack, API dan hybrid; menolak overwrite dan membuat secret lokal privat.
- Boilerplate dengan custom User, contoh Project, HTML/API/admin, migrations, uv lockfile, Docker/Compose dan CI configuration.
- Validasi tiga mode, schema API, credential/CSRF flow, browser desktop/mobile, static assets Docker dan 26 tests PostgreSQL.

Baseline contoh menggunakan single-owner Project. Integrasi opsional, external hosting/TLS dan SMTP provider perlu disesuaikan serta diuji pada proyek tujuan. Skill tidak menyediakan server MCP terpisah.
